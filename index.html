Cómo usar la calculadora

Completa los datos de la columna, selecciona el método y pulsa Calcular varillas. Los cálculos se realizan únicamente en tu dispositivo.

  • Instalar: añade la aplicación cuando el navegador lo permita.
  • Compartir: abre una hoja con destinos y opciones para enviar o copiar el enlace actual.
  • Tema: alterna entre apariencia oscura y clara.
  • Restablecer: recupera todos los valores iniciales.
  • Ayuda: abre esta guía; también puedes cerrarla con Escape.

Herramienta académica: el diseño final debe revisarse con un ingeniero estructural.

4. ¿Cómo se determina el acero?
